## 遊戲設計文件：新手教學 - 「啟航」

**遊戲名稱暫定:** 《深海蒸汽奇航》 (或類似蒸氣龐克風格名稱)

**遊戲類型:** 2.5D 俯視視角，冒險探索，資源管理，建造與戰鬥

**風格:** 蒸氣龐克 (Steampunk)

**教學目標:**
讓玩家熟悉基礎角色操作、船隻操作、資源收集、船隻維修與啟動、以及首次航行體驗。教學過程將提供「自由探索」的錯覺，但最終引導玩家完成所有核心機制學習。

### 1. 故事背景與教學情境

*   **開場:** 玩家角色從一艘毀損的浮空平台（或漂浮廢墟）上醒來，周圍是濃霧彌漫的海洋和一些漂浮的殘骸。遠處隱約可見一座破舊的港口島嶼。
*   **目標:** 玩家必須想辦法啟動附近一艘廢棄的蒸氣船，並航向那座港口島嶼尋找補給和可能的生存線索。

### 2. 教學流程詳情

#### **階段一：平台上的覺醒與基礎操作 (Wake Up & Basic Controls on Platform)**

*   **環境:** 一個小型、安全的廢棄金屬平台，周圍有少量無害的漂浮物。
*   **敘事引導:** 角色意識到自己身處險境，必須移動並自衛。
*   **教學內容:**
    1.  **移動 (Movement):**
        *   **指示:** 畫面中央出現 UI 提示：「使用 WASD (或左搖桿) 移動角色」。
        *   **實踐:** 玩家移動角色。可能有一條發光的「路徑」指引玩家走向平台邊緣。
        *   **反饋:** 成功移動後提示消失，或轉為下一個教學提示。
    2.  **攻擊 (Attack):**
        *   **指示:** 畫面中央出現 UI 提示：「點擊滑鼠左鍵 (或攻擊按鈕) 進行基礎攻擊」。
        *   **實踐:** 平台邊緣可能設置一個簡單的「訓練假人」或一塊漂浮的脆弱廢鐵，玩家需要攻擊它。
        *   **反饋:** 成功攻擊並摧毀目標後提示消失。

*   **自由探索元素:** 玩家可以在小平台範圍內自由移動和攻擊，但除了指引的目標外，沒有其他互動點。
*   **下一步引導:** 當玩家完成基礎攻擊後，鏡頭會輕微轉向，或 UI 箭頭指向遠處的「船」。提示：「前方似乎有一艘廢棄的船，或許可以加以利用。」

#### **階段二：發現船隻與魚叉砲台操作 (Discovering the Boat & Harpoon Turret)**

*   **環境:** 玩家角色需要移動到平台邊緣，然後跳上一艘破舊的蒸氣船。船上顯眼處有一座魚叉砲台。周圍水域漂浮著一些「箱子」和幾隻溫馴的「水下廢鐵獸」（或類似蒸氣龐克風格的低階怪物）。
*   **教學內容:**
    1.  **登船 (Boarding the Boat):**
        *   **指示:** 當角色靠近船隻時，提示：「按下 F (或互動按鈕) 進入船隻。」
        *   **實踐:** 玩家登船，角色會自動進入船隻的控制/行動模式。
    2.  **魚叉砲台 (Harpoon Turret):**
        *   **指示:** 船上自動切換視角到魚叉砲台，提示：「使用滑鼠 (或右搖桿) 瞄準，點擊滑鼠左鍵 (或射擊按鈕) 發射魚叉。」
        *   **實踐 (收集箱子):**
            *   **目標:** 水域中漂浮著一個顯眼的「木板與煤炭箱」。
            *   **指示:** 提示：「船身破損，需要木板修復。用魚叉勾住箱子！」
            *   **實踐:** 玩家射出魚叉，勾住箱子，箱子會被牽引到船邊緣，自動吸附或提示玩家收取資源。
            *   **反饋:** 成功後箱子消失，資源自動進入玩家簡易背包，提示下一個步驟。
        *   **實踐 (捕獲怪物):**
            *   **目標:** 附近有一隻溫馴的「水下廢鐵獸」，外觀可能是一些生鏽的機械部件組成的螃蟹或魚。
            *   **指示:** 提示：「船的引擎鍋爐似乎損壞了，需要特殊的零件才能修復。試著捕捉並擊敗水下廢鐵獸！」
            *   **實踐:** 玩家再次使用魚叉勾住怪物。怪物被勾住後會被牽引到船邊緣，此時角色會自動切換為戰鬥模式。
            *   **實踐 (擊敗怪物):** 玩家使用基礎攻擊擊敗被勾住的怪物。
            *   **反饋:** 怪物死亡後掉落「鍋爐零件」。提示：「獲得鍋爐零件！」

*   **自由探索元素:** 玩家可以在魚叉砲台模式下自由瞄準和射擊，可以嘗試勾住多個箱子或怪物（雖然教學階段通常只出現一個關鍵目標）。

#### **階段三：船隻維修與燃料 (Boat Repair & Fueling)**

*   **環境:** 玩家在船上，船體多處破損（甲板有破洞，鍋爐冒黑煙）。
*   **教學內容:**
    1.  **修復鍋爐 (Repairing the Boiler):**
        *   **指示:** 提示：「鍋爐嚴重損壞，使用『鍋爐零件』進行維修。」船上的鍋爐會發光。
        *   **實踐:** 玩家走向鍋爐，互動 (F 鍵或互動按鈕)，彈出簡易維修介面。自動使用背包中的「鍋爐零件」完成修復。
        *   **反饋:** 鍋爐修復完成，冒出的黑煙變為白色蒸汽。
    2.  **修復甲板 (Repairing the Deck):**
        *   **指示:** 提示：「甲板多處破損，使用『木板』進行修復，否則航行時可能會有危險。」甲板的破洞會發光。
        *   **實踐:** 玩家走向甲板破洞，互動，自動使用背包中的「木板」完成修復。
        *   **反饋:** 甲板修復完成。
    3.  **為鍋爐加料 (Fueling the Boiler):**
        *   **指示:** 提示：「鍋爐已修復，但沒有燃料無法啟動。將『煤炭』投入鍋爐。」鍋爐加料口會發光。
        *   **實踐:** 玩家走向鍋爐加料口，互動，自動使用背包中的「煤炭」進行加料。
        *   **反饋:** 鍋爐燃料槽滿。
    4.  **啟動船隻 (Starting the Boat):**
        *   **指示:** 提示：「所有準備就緒，啟動船隻，航向未知！」船舵位置發光。
        *   **實踐:** 玩家走向船舵，互動。船隻引擎開始轟鳴，螺旋槳轉動。
        *   **反饋:** 船隻成功啟動，鏡頭拉遠，進入航行模式。

*   **自由探索元素:** 玩家可以在船上自由走動，但在這些關鍵維修點互動前，船隻無法啟動。

#### **階段四：航向第一座島嶼 - 碼頭倉庫 (Sailing to the First Island - Dock Warehouse)**

*   **環境:** 船隻在開放水域航行，遠方有迷霧中的一座島嶼，島上可見一座破舊的「碼頭倉庫」。
*   **教學內容:**
    1.  **船隻航行 (Boat Sailing):**
        *   **指示:** 畫面出現 UI 提示：「使用 WASD (或左搖桿) 駕駛船隻，航向遠方燈塔 (或碼頭倉庫標記)。」
        *   **實踐:** 玩家駕駛船隻向目標移動。
        *   **反饋:** 船隻順利航行，目標點在小地圖上標示。
    2.  **抵達目標 (Reaching the Destination):**
        *   **目標:** 碼頭倉庫。
        *   **指示:** 提示：「抵達碼頭倉庫，小心停靠！」碼頭邊緣會出現一個停靠區的光圈。
        *   **實踐:** 玩家將船隻駛入停靠區。
        *   **反饋:** 船隻自動停靠，進入島嶼探索模式或過場動畫。

*   **自由探索元素:** 玩家可以在前往碼頭倉庫的路上短暫地在水域中航行，體驗船隻的移動感。但此階段通常不會有額外的互動點或危險，以確保玩家順利抵達。

### 3. UI/UX 考量

*   **文字提示 (Text Prompts):** 簡潔明瞭，用醒目字體顯示在畫面中央，完成動作後自動消失。
*   **視覺引導 (Visual Cues):**
    *   **發光效果:** 互動目標 (如：假人、箱子、怪物、鍋爐、甲板、船舵) 會發出微光。
    *   **箭頭指示:** 指引玩家移動方向或下一步目標。
    *   **高亮區塊:** 停靠區塊會有明顯的邊界光。
*   **音效反饋 (Audio Feedback):**
    *   **成功音效:** 完成一個教學步驟時有提示音。
    *   **失敗音效:** (如：魚叉射偏) 提供輕微提示。
    *   **環境音效:** 鍋爐啟動、引擎轟鳴等。
*   **簡易背包/資源顯示:** 教學期間只需簡單顯示獲得的資源，無需完整背包介面。
*   **進度條:** 維修和燃料加注時可顯示進度條。

### 4. 難度曲線

*   **極低難度:** 教學階段的怪物非常弱，不會主動攻擊，甚至不會反擊。資源充足，確保玩家能一步步完成所有任務。
*   **引導明確:** 讓玩家在「自由」的過程中，不斷有清晰的目標和指引，避免卡關。

### 5. 後續內容預告

*   當玩家成功抵達碼頭倉庫後，可以播放一段簡短的過場動畫，預告更廣闊的世界、更強大的怪物和更多的挑戰，正式開啟遊戲主線。
