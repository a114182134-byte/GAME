## 遊戲新手教學：啟程之風

**風格：** 蒸氣龐克、2.5D 俯視視角
**核心機制教學：** 移動、攻擊、物品拾取與箱子互動、船隻操作、資源管理、航行。

---

### 第一階段：平台醒來與基本操作教學

**場景：**
玩家從一個充滿鏽蝕金屬、冒著白煙的管道、閃爍著古老電弧燈光的狹小維修平台醒來。周圍是深不見底的蒸汽迷霧。

**教學流程：**

1.  **醒來與移動 (UI 提示：使用 WASD/方向鍵 移動)**
    *   角色緩緩睜開眼睛，發出低沉的機械聲響。
    *   UI 提示：「你的動力爐還在運作嗎？試著移動身體。」
    *   當玩家移動時，角色身上的齒輪和活塞會輕微轉動，發出機械摩擦聲。
    *   移動到平台邊緣時，會有柵欄或斷裂的橋樑，阻止玩家離開。

2.  **攻擊 (UI 提示：滑鼠左鍵/指定按鍵 攻擊)**
    *   移動過程中，會遇到幾個小型、不具威脅的「齒輪甲蟲」或「維修機器人」殘骸，它們會發出輕微的嗡鳴聲，偶爾噴出幾縷蒸汽。
    *   UI 提示：「這些老舊的機械殘骸礙手礙腳，試著揮舞你的工具將它們清理掉。」
    *   玩家預設裝備一把造型獨特的「蒸氣扳手」或「電弧拳套」。
    *   擊敗齒輪甲蟲會掉落無用的「碎鐵片」，但不需教學拾取。
    *   當玩家成功擊敗至少一個敵人後，UI 提示：「不錯，你的武器還算順手。」

3.  **單一物品拾取 (UI 提示：靠近物品按 E 拾取)**
    *   在平台一角，有一個閃爍著微光的「發條零件」。
    *   UI 提示：「有個零件掉落了，你一次只能攜帶一件物品，試著把它撿起來。」
    *   玩家拾取「發條零件」。物品會顯示在 HUD 上。
    *   嘗試拾取附近的第二個「發條零件」或「碎鐵片」時，UI 提示：「你一次只能攜帶一件物品，如果想拿別的，需要先放下手中的。」
    *   UI 提示：「按 Q 鍵可以放下物品。」(讓玩家放下發條零件，完成教學)。

4.  **箱子互動與慢動作 (UI 提示：靠近箱子按 E 互動)**
    *   在平台中央，有一個鏽蝕的「緊急補給箱」。
    *   UI 提示：「這個補給箱似乎能提供一些幫助。」
    *   當玩家靠近並按 E 鍵互動時，遊戲畫面會自動進入**慢動作**。
    *   箱子打開，浮現 3-4 個物品選項 (例如：「小型發電機」、「舊地圖」、「蒸汽罐」)。
    *   UI 提示：「在慢動作中選擇你需要的物品，一次只能拿一件。」
    *   玩家選擇一個物品 (例如：「小型發電機」)。物品會自動拾取並退出慢動作。
    *   讓玩家練習拾取與放下。

### 第二階段：找到船與準備啟程

**場景：**
維修平台連接到一個稍微寬廣的碼頭，碼頭邊停泊著一艘龐大但破舊的「蒸氣飛艇殘骸改裝船」—— **「鋼鐵海豚號」**。船身多處可見破損，鍋爐冒著黑煙，甲板上有些破洞。船頭裝著一門巨大的「魚叉砲台」。

**教學流程：**

1.  **發現船隻**
    *   UI 提示：「遠方那艘船，或許是離開這裡的關鍵。」
    *   引導玩家走向「鋼鐵海豚號」。

2.  **船隻狀態檢視**
    *   靠近船隻後，HUD 上會顯示船隻簡要狀態：「鋼鐵海豚號 - 鍋爐損壞 (需修復)、甲板破損 (需修復)。」
    *   鏡頭稍微拉近，特寫鍋爐與甲板的破損處。
    *   UI 提示：「我們的船需要修理才能啟動，鍋爐和甲板都壞了。它還需要燃料。」

3.  **魚叉砲台操作**
    *   走到船頭的「魚叉砲台」前，UI 提示：「這門砲台可以用來捕獲一些東西。」
    *   UI 提示：「使用魚叉砲台瞄準並射擊 (右鍵瞄準，左鍵射擊)。」
    *   在船隻周圍的水域或空中，會刷新幾隻中型、緩慢移動的「蒸汽水母」或「浮空章魚」(不具攻擊性，或攻擊力極低)。
    *   UI 提示：「試著用魚叉砲台捕獲那些生物。將它們拉到船上。」

4.  **捕獲與安置**
    *   當玩家用魚叉擊中生物後，生物會被魚叉牽引。
    *   UI 提示：「按住左鍵將目標拖拽到船上。拖到甲板指定區域時鬆開。」
    *   玩家成功將生物拖拽到船上後，UI 提示：「目標已安置上船！現在是時候處理它們了。」
    *   **安置箱子：** 在碼頭上，會出現一個特別標記的「貨運箱」。
        *   UI 提示：「這個貨運箱看起來適合直接安置到船上，它能儲存任何東西。」
        *   玩家拾取「貨運箱」（此時玩家物品欄會顯示「貨運箱」）。
        *   將貨運箱帶到船上指定區域並按 E 安置。
        *   UI 提示：「貨運箱已安置！之後你可以將物品放入其中，或從中取出。」

5.  **擊殺怪物與獲取零件**
    *   被安置到船上的蒸汽水母/浮空章魚現在會變成敵對狀態 (但攻擊力依然很低)。
    *   UI 提示：「清理這些生物以獲取修理鍋爐所需的零件。」
    *   玩家使用蒸氣扳手/電弧拳套擊殺船上的怪物。
    *   怪物死亡後會掉落「鍋爐碎片」。
    *   UI 提示：「你獲得了鍋爐碎片，它們可以用來修復鍋爐。」
    *   讓玩家收集足夠的鍋爐碎片 (例如：3 個)。

6.  **修復鍋爐**
    *   走到船上破損的鍋爐前。
    *   UI 提示：「鍋爐嚴重損壞，使用鍋爐碎片修復它。」
    *   按 E 鍵互動，消耗掉所有「鍋爐碎片」，鍋爐視覺上得到修復，黑煙變成淡灰色蒸汽。
    *   UI 提示：「鍋爐已修復，現在它需要燃料才能運作。」

7.  **修理甲板與餵食鍋爐**
    *   走到船上已經安置好的「貨運箱」旁。
    *   UI 提示：「我們還需要木板來修復甲板，以及煤炭來啟動鍋爐。貨運箱裡或許有這些東西。」
    *   玩家與「貨運箱」互動，進入**慢動作**。
    *   箱子裡提供「木板」和「煤炭」選項，玩家分兩次取出。
    *   **修復甲板：** 拾取「木板」。走到甲板破損處，按 E 修復。甲板視覺上修復。
    *   **餵食鍋爐：** 拾取「煤炭」。走到鍋爐旁，按 E 餵食。鍋爐發出更強的蒸汽聲，火焰更加明亮。
    *   UI 提示：「鍋爐已準備就緒，船隻可以啟動了！」

### 第三階段：航向第一座島 - 碼頭倉庫

**場景：**
船隻啟動後，鏡頭切換為 2.5D 俯視視角，顯示船隻航行在廣闊的蒸汽海域上。遠方可見一座被蒸汽籠罩的島嶼，島上有一座巨大的「碼頭倉庫」建築。

**教學流程：**

1.  **啟動與航行 (UI 提示：WASD 控制方向)**
    *   UI 提示：「前往駕駛舵輪 (位於船尾)，按 E 啟動航行。」
    *   玩家啟動航行後，鏡頭轉為 2.5D 俯視。
    *   UI 提示：「使用 WASD 控制船隻的移動方向，航向遠方的碼頭倉庫。」
    *   船隻會以基礎速度前進，玩家可以左右轉向。
    *   在航行過程中，偶爾會有「蒸氣噴泉」或「漂浮的廢棄物」作為輕微的障礙物，讓玩家練習轉向。

2.  **目標指示**
    *   地圖上會顯示前往「碼頭倉庫」的路線或目標點，輔助玩家導航。
    *   UI 提示：「你的目的地是第一座島嶼：碼頭倉庫。」

3.  **抵達與教學結束**
    *   當船隻靠近「碼頭倉庫」的碼頭區域時，會觸發自動靠岸。
    *   UI 提示：「你已抵達碼頭倉庫！新手教學結束。」
    *   遊戲畫面漸暗，進入下一個章節或遊戲主介面。

---

**總結此教學關卡的「自由探索但最終還是要做」的設計理念：**

*   **平台階段：** 玩家可以在平台上自由移動和攻擊，但只有與箱子互動才能獲取進一步的資訊或物品。
*   **船隻準備階段：** 玩家可以先修理甲板或鍋爐，也可以先去捕獲怪物，沒有嚴格的線性順序，但最終所有步驟（捕獲、擊殺、修復、餵食）都必須完成才能啟動船隻。
*   **航行階段：** 玩家可以在蒸汽海域上稍作探索，但主要目標始終是碼頭倉庫，並且會被明確提示。

整個教學流程會通過 UI 提示、鏡頭引導和環境設計，逐步引導玩家了解遊戲的核心機制，同時不失蒸汽龐克世界的探索感。
