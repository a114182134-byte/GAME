## 《餘燼航路：鏽蝕重生》開發日誌
**日期：** 2023年10月27日
**整理人：** 素材分析官

### **今日進度與重點摘要：**
本日會議重點在於確立 Godot 4 環境下的核心技術實踐、深化世界觀美術風格的改造方向，並勾勒教學關卡的初步流程。團隊已明確了多項關鍵開發指標與美術設計原則，旨在將「末世生存的絕望感」與「機械操作的爽快感」完美結合。

### **1. 核心開發指標與技術實踐決策 (Godot 4)**

*   **時間控制機制確認：**
    *   已確認 Boss 戰中，當使用 `Engine.time_scale` 進行物理減速時，必須對 UI 相關的 `Tween` 動畫額外呼叫 `tween.set_ignore_time_scale(true)`。此舉將確保 UI 互動與動畫不受減速影響，維持玩家操作手感。
*   **碰撞系統優化方案確立：**
    *   **船體碰撞：** 為避免大型船體 Sprite 帶來的複雜碰撞問題，已決定在船隻中心建立一個 `Area2D` 作為「核心 Hitbox」，而周圍 Sprite 僅作為視覺元素。
    *   **Graze System (刮擦獎勵)：** 將引入一個中等大小的「感知圓環」`Area2D` 來偵測彈幕。透過其 `area_entered` 訊號實作充能機制，鼓勵玩家進行高風險的邊緣遊玩以獲取獎勵。
*   **資料持久化與擴充性架構：**
    *   **單例管理：** 確立使用 `GameData.gd` 作為單例 (Autoload) 來集中管理遊戲內所有資源，確保資料的統一性與易於存取。
    *   **資源物件：** 將利用 Godot 的 `Resource` 物件來儲存塔防 Grid 數據，此設計有助於未來關卡內容的快速擴充與迭代。
*   **模組化設計強制實施：**
    *   **狀態機模式：** 已決定強制實施 `StateMachine` 模式來處理遊戲中「航行、戰鬥、防禦」三種核心模式的切換，以避免 `if-else` 地獄式邏輯，提升程式碼的可維護性與清晰度。

### **2. 世界觀風格重塑與美術方向確認**

根據「黃銅蒸氣末世」的硬核美學，已對「生物/魔法」元素進行**科技異文化改造**，相關概念已定案：

*   **異變概念改造：**
    *   原先的「生物龐克異變」將完全轉化為**「異變機械體 (Mutated Automatons)」**：表現為鏽蝕膠質纏繞、增生金屬結構。
    *   「魔法龐克能力」將被重新定義為**「虛空擾動單元 (Void Disturbance Units)」**：其效果將透過粒子加速、空間扭曲、能量場投射等科技感表現。
    *   「魔法器械進行曲」則改為**「失控自走遺跡哨兵 (Rogue Sentinels)」**：強調是古代維安機械因不明原因而失控。
    *   道具「黏液瓶/洽比」統一替換為更符合機械主題的**「冷凝劑/高壓油/能量核心」**，作為化學品與反應催化劑。
*   **美術與敘事總結：**
    *   **核心邏輯：** 所有異變都將被解釋為「古文明科技因虛空腐蝕而產生的物理變異」，強調科技異變而非生物或純魔法。
    *   **視覺規範：** 美術設計將嚴格遵循黃銅、齒輪、皮革的質感，並搭配冷色調的粒子光效。徹底拒絕傳統奇幻遊戲中常見的鮮豔色彩。

### **3. 教學關卡與流程設計原則**

已確立教學流程將採取「自由探索與導向任務並行」的模式，以確保玩家逐步熟悉核心玩法循環：

*   **教學流程階段：**
    1.  **覺醒與基礎：** 玩家將透過平台跳躍練習移動與攻擊，建立基礎操控感。
    2.  **船隻維修：** 強制執行「捕獲（魚叉）-> 擊殺 -> 回收零件 -> 修理」的完整工業循環，讓玩家熟悉資源獲取與維護機制。
    3.  **航行體驗：** 引導玩家駕駛「鋼鐵海豚號」前往碼頭倉庫，期間穿插輕微的障礙導航，熟悉航行操作。
*   **沉浸感實作提示：**
    *   將在場景切換時使用「過場動畫」來掩蓋資料載入，確保遊戲體驗的流暢性與沉浸感。

### **4. 下一步行動計畫**

團隊已明確以下模組為近期開發的優先重點：

1.  **Prototype (原型) 開發：** 實現「船隻固定、背景移動」的捲軸系統，並整合 `Area2D` 核心點偵測，作為遊戲的基礎運行框架。
2.  **E 鍵環形選單 (UI) 設計與實作：** 此為遊戲靈魂之一。將優先完成其數學邏輯模型，確保選單在不同解析度下的響應式表現。
3.  **資源數據結構 (`GameData`) 確立：** 建立 `GameData` 類別，確保「航行資源 -> 防禦塔建設 -> Boss 戰術消耗」的閉環邏輯能夠正確運算，為後續玩法提供穩定數據基礎。
