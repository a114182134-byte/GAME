## 美術素材分析報告：二姐提供的「KP-17 手槍」

**專案名稱：** 《餘燼航路：鏽蝕重生》
**核心美術風格：** 黃銅蒸氣風 + 末世感
**素材來源：** 二姐提供
**開發者參考：** 小白龍

---

### 1. 風格檢查：是否符合「黃銅蒸氣風 + 末世感」？

*   **黃銅蒸氣風 (Brass Steampunk)：** **不符合。**
    *   這把手槍是典型的現代聚合物手槍設計，線條流暢、簡潔，缺乏黃銅、齒輪、蒸汽管線、鉚釘、複雜機械結構等蒸氣龐克標誌性元素。整體材質為黑色塑膠和金屬，沒有黃銅的暖色調和復古質感。
*   **末世感 (Post-Apocalyptic)：** **不符合。**
    *   圖片中的手槍看起來是全新的，光潔無瑕，沒有任何磨損、鏽蝕、刮痕、修補痕跡或灰塵積累，完全沒有經歷過末世浩劫的滄桑感。

**總結：** 就目前的形態而言，這把手槍**完全不符合**我們遊戲的「黃銅蒸氣風 + 末世感」美術風格。它更像是一把現代軍事或執法風格的武器。

---

### 2. 資產分類：這屬於「船隻零件」、「碼頭建築」、「虛空銀行道具」還是「角色服飾」？

*   這顯然是一把**手持武器**。
*   在提供的選項中，它最接近**「角色服飾」**（廣義上指角色所穿戴或攜帶的裝備）。
    *   如果遊戲中有設定，此類現代武器極為稀有，是末世前遺留下來的珍貴「遺物」，那麼它也可能被歸類為**「虛空銀行道具」**中的一種特殊戰利品或收藏品。
    *   但若作為一般戰鬥用途，它會是角色最直接的戰鬥裝備。

**建議：** 姑且先將它視為**「角色武器裝備」**，需要經過大量改裝才能符合風格。若要作為「虛空銀行」內的特殊物品，則更需強調其「末世遺物」的稀有性和與現代科技的連結。

---

### 3. 架構建議：請給開發者「小白龍」一些 Godot 開發建議

小白龍你好！既然二姐提供了這個靈感，我們可以將它視為一個「原型武器」的基底，然後進行大刀闊斧的改裝，讓它融入遊戲世界。

1.  **3D 模型處理（若為3D遊戲）：**
    *   **Shader 效果：**
        *   **材質疊加與侵蝕：** 針對「黃銅蒸氣風 + 末世感」，你需要一個複雜的 PBR (Physically Based Rendering) Shader。
            *   **基底材質替換：** 將現有的黑色塑膠材質替換為磨損的黃銅、生鏽的鋼鐵、老化的皮革或木材。
            *   **鏽蝕與灰塵層：** 製作一個能夠根據模型邊緣、凹陷處疊加鏽蝕、灰塵或油漬的 Shader。可以利用環境光遮蔽 (Ambient Occlusion) 或自定義紋理遮罩 (Mask Texture) 來控制這些效果的分佈。
            *   **蒸汽/熱能效果：** 如果要強調「蒸氣」屬性，可以在武器某些部位（如排氣口、連接管）添加熱擾動 (Heat Distortion) 效果的 Shader，讓空氣看起來微微扭曲。
            *   **光澤與反射：** 黃銅材質需要精確的粗糙度 (Roughness) 和金屬度 (Metallic) 貼圖，表現出歲月磨礪後的斑駁光澤。
        *   **程序化磨損：** 可以考慮使用 Godot 的 `VisualShader` 或寫 `ShaderMaterial`，加入程序化噪點 (Noise) 來模擬隨機的刮痕和磨損，而非完全依賴紋理繪製。
    *   **碰撞箱設定 (CollisionShape)：**
        *   **精細化拾取/放置：** 作為角色手持武器，模型的碰撞箱可以相對簡化，例如使用 `BoxShape3D` 或 `ConvexPolygonShape3D` 包裹其主要輪廓。
        *   **射擊判定：** 如果子彈是從槍口射出，則在槍口位置設置一個 `RayCast3D` 或 `Area3D` 用於檢測命中目標。
        *   **世界互動：** 若武器可以掉落在地上，確保其碰撞箱能與地面或其他物體正確交互，不會穿模。
    *   **骨骼與動畫：** 為武器模型添加必要的骨骼 (Skeleton3D)，例如扳機、滑套、彈匣，以便在腳本中控制其射擊、換彈等動畫。

2.  **GDScript 腳本（`weapon.gd` 或類似）：**
    *   **繼承與架構：**
        ```gdscript
        # weapon.gd (通用武器基底類別)
        class_name Weapon extends Node3D # 如果是3D武器
        
        @export var weapon_name: String = "未命名武器"
        @export var damage: float = 10.0
        @export var fire_rate: float = 0.5 # 射擊間隔時間
        @export var max_ammo: int = 10
        @export var current_ammo: int = 10
        @export var reload_time: float = 2.0
        @export var durability: float = 100.0 # 末世感，耐久度是重要屬性
        @export var material_cost: Dictionary # 用於工作台維修或升級
        
        var can_fire: bool = true
        var is_reloading: bool = false
        
        signal fired(projectile_origin: Node3D, direction: Vector3)
        signal reloaded()
        signal out_of_ammo()
        signal weapon_broken()
        
        func _ready():
            pass # 可以在這裡初始化UI顯示等等
            
        func _process(delta):
            # 可以在這裡處理一些UI更新或者動態效果
            pass
        
        func primary_action(): # 射擊
            if can_fire and not is_reloading and current_ammo > 0:
                _play_fire_animation()
                _spawn_projectile()
                current_ammo -= 1
                can_fire = false
                _apply_recoil()
                await get_tree().create_timer(fire_rate).timeout
                can_fire = true
                if current_ammo <= 0:
                    emit_signal("out_of_ammo")
            elif current_ammo <= 0 and not is_reloading:
                print("Click! Out of ammo!") # 播放空彈匣音效
        
        func secondary_action(): # 換彈
            if not is_reloading and current_ammo < max_ammo:
                _start_reload()
        
        func _start_reload():
            is_reloading = true
            _play_reload_animation()
            await get_tree().create_timer(reload_time).timeout
            current_ammo = max_ammo
            is_reloading = false
            emit_signal("reloaded")
        
        func take_damage(amount: float): # 處理武器耐久度
            durability -= amount
            if durability <= 0:
                durability = 0
                emit_signal("weapon_broken")
                print("Weapon is broken!")
        
        # 抽象方法，讓子類實作具體效果
        func _play_fire_animation(): pass
        func _spawn_projectile(): pass
        func _apply_recoil(): pass
        func _play_reload_animation(): pass
        ```

### 4. 改進方向：如果要更精緻，建議還可以加入什麼元素？

這把手槍有潛力成為一把非常獨特的武器，但需要大量的美術改造。

1.  **材質與細節重構：**
    *   **主體材質：** 將原有的黑色聚合物替換為厚重的**黃銅**或**青銅**，並點綴以深色、鏽蝕的**鋼鐵**部件。
    *   **木質握把：** 握把部分可以改為磨損的**硬木**，上面雕刻著符文或遊戲世界的標誌。
    *   **鉚釘與接縫：** 增加大量的**鉚釘、螺栓**以及明顯的**焊接痕跡**，強化其手工製作和末世修補的質感。
    *   **蒸氣管線：** 在槍身側面、頂部或底部增加微型的**黃銅或銅質管線**，連接到小型的**壓力表**或**蒸汽閥門**，暗示其由蒸汽驅動。
    *   **齒輪與機械結構：** 槍身部分區域可以設計成半開放式，露出運轉中的**齒輪、彈簧或連桿**，強調蒸氣龐克的機械美學。
    *   **蝕刻與雕刻：** 在黃銅表面蝕刻上精緻的**圖案、符號或文字**，增加其歷史感和獨特性。
    *   **鏽蝕與汙垢：** 加入細緻的**鏽斑、油漬、刮痕和磨損**，特別是在經常觸摸和容易磨損的邊角處，展現末世的生存痕跡。

2.  **造型與輪廓調整：**
    *   **加厚槍身：** 使整體造型更為厚重、粗獷，而非現代手槍的纖細流線型。
    *   **誇張的槍口：** 設計一個帶有散熱孔或蒸氣噴射口的特殊槍口，讓它看起來更有力量感。
    *   **不對稱設計：** 局部加入一些不對稱的改造，例如一側有額外的護甲板、另一側有外露的機械部件，營造出拼湊、改裝的風格。

3.  **功能性與視覺敘事：**
    *   **彈藥機制：** 考慮使用非傳統的彈藥，例如：
        *   **蒸汽彈匣：** 不只裝子彈，還裝有小型的燃料或蒸汽核心。
        *   **手動上膛機構：** 每次射擊後可能需要拉動一個額外的槓桿或旋鈕來進行上膛。
    *   **發射效果：**
        *   **槍口火焰：** 帶有黃色、橙色火光，並伴隨大量**白色蒸汽**噴出。
        *   **聲音設計：** 發射時結合**蒸汽嘶嘶聲、齒輪轉動聲和沉重的機械撞擊聲**，營造獨特聽覺體驗。
    *   **動態發光：** 如果有內部蒸汽反應爐，可以考慮在某些鏤空處有微弱的**橙色或藍色光芒**，暗示能量核心的存在。
